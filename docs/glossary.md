# Glossary

**Batch** — Ordered set of canonical records represented by one commitment.

**Block** — Protocol object linking commitments to previous finalized history.

**Canonicalization** — Versioned deterministic conversion from accepted input to
bytes that can be hashed consistently.

**Commitment** — Compact cryptographic binding to a batch and its context.

**Finality** — Protocol state in which a block is considered committed.

**Inclusion proof** — Data needed to recompute a committed Merkle root from one
record.

**Merkle root** — Single hash committing to every leaf in a Merkle tree.

**OTLP** — OpenTelemetry Protocol, used to transport telemetry data.

**Quantum-resistant** — Designed to resist known classical and quantum attacks
under stated assumptions; not a guarantee against all future attacks.

**Span** — One timed operation within an OpenTelemetry trace.

**Validator** — Authorized node that participates in block validation and
finalization.
